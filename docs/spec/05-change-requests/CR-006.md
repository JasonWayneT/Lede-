## Request

Music Roadmap Phase 5 (`docs/music/ROADMAP.md`): mix the selected music into the briefing audio —
ducked beds under each story's narration, and the intro/outro/section-transition stingers — using
the segment plan and durations from Phase 4. Produce the same single `briefing.mp3`, non-fatally.
Make music the first audible outcome of the whole music feature. See `ADR-005` for the toolkit and
format decisions (numpy + scipy + soundfile, 44.1 kHz stereo, mix inline, zero new deps).
