## Request

Fix `BUG-009`: an audit pass flagged that Depth and LLM Provider settings forms in `settings.html`
submit as HTML forms while their routes expected JSON bodies — the same defect class as `BUG-002`,
which fixed Gmail/Schedule/TTS but missed these two. Convert both routes to `Form(...)` parameters.
