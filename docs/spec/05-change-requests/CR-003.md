## Request

Music Roadmap Phase 2 (`docs/music/ROADMAP.md`): the frame stage's existing structured-output LLM
call should also classify each story's `sensitivity` and `story_weight`, so that later phases
(Phase 3 selection, Phase 5 mixing) have the signal they need to gate and tune background music —
without adding a separate classification LLM call, and without adding fields that have no V1
consumer. See `ADR-002` for why this is two fields, not the original report's four.

Note: this CR was originally drafted as `CR-002` before a concurrent background session claimed
that ID (and `BUG-002..004`, `AC-061..066`, `TEST-012..013`, `TASK-015..018`) fixing unrelated
pre-existing test failures. Renumbered to `CR-003` to avoid collision — see that session's
`CR-002.md` for the unrelated work.
