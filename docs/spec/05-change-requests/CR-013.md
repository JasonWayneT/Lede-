## Items assessed but not fixed in this pass (flagged for owner)

- **R7 (retry logic duplication)**: `briefings.retry_run`'s `_resume` re-implements
  `orchestrator.run_pipeline`'s stage loop/completion logic rather than sharing it. A shared-helper
  refactor is reasonable but touches the core retry/completion path — higher risk than the other
  fixes here. Not refactored in this pass; `BUG-018` (a real bug found via this duplication) was
  fixed directly instead of via a broader refactor.
- **R8 (daemon PID-reuse race)**: closing this properly requires either a new dependency
  (`psutil`, for reliable cross-platform process-identity checks) or a subprocess-based check
  (`ps`/`tasklist`) run on every dashboard load — both are real cost/dependency tradeoffs this
  project's own rules (`AGENTS.md`: "No dependencies not listed in the project's dependency file —
  flag before adding any") require flagging rather than deciding silently. Given the low probability
  of PID reuse in the narrow window between a daemon dying and the next liveness check on a
  single-user local machine, this was left unfixed and flagged for Jason's call rather than adding
  a dependency unprompted.
