# Bug: BUG-008 SSRF in article ingest

## Metadata

- Bug ID: `BUG-008`
- Severity: High
- Status: fixed
- Found: 2026-07-06 (audit pass, finding S1)
- Fixed: 2026-07-06

## Description

`app/services/article.py` fetched whatever URL a user supplied — directly via `trafilatura.fetch_url`
and indirectly via the Jina Reader proxy — with no restriction on scheme or destination host. The
URL reaches this code from `POST /api/briefings/on-demand`, a live, unauthenticated (localhost-only,
but reachable to anything on the machine, including MCP automation) endpoint. A URL such as
`http://127.0.0.1:<internal-port>/...` or `http://169.254.169.254/...` (a common cloud metadata
address) would be fetched server-side and its response folded directly into a briefing.

## Impact

- Server-side request forgery: the tool could be tricked into making requests to internal services
  or cloud metadata endpoints on behalf of a user (or anything driving the on-demand endpoint) and
  leaking the response into briefing content.
- Severity is tempered for a single-user local tool, but this is exactly the class of bug that
  matters most once the project's stated goal of "other builders can clone and run this" is taken
  seriously (`DEFINITION_OF_DONE.md`).

## Root cause

No URL validation existed before either extractor's outbound fetch.

## Fix

Added `_is_url_safe_to_fetch(url)` in `app/services/article.py`: rejects non-`http`/`https` schemes,
resolves the hostname, and rejects the URL if any resolved address is loopback, private, link-local,
multicast, or reserved. Applied once in `fetch_article()` before either extractor runs, so both the
direct `trafilatura` fetch and the Jina Reader path are covered. Fails open (allows the URL through
to fail naturally downstream) if DNS simply doesn't resolve or times out — that's an ordinary fetch
failure, not a security concern, and treating it as unsafe would make the guard indistinguishable
from a flaky network in the audit log.

## Regression tests

`tests/services/test_article.py`: rejects non-http(s) schemes, rejects loopback/localhost/link-local
(cloud metadata)/private-network addresses, allows a mocked public IP, fails open on unresolvable
DNS and on DNS timeout, and confirms `fetch_article()` short-circuits before calling
`_trafilatura_extract` for an unsafe URL.
