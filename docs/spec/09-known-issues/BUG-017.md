# Bug: BUG-017 No cap on on-demand ingest URL count

## Metadata

- Bug ID: `BUG-017`
- Severity: Medium
- Status: fixed
- Found: 2026-07-06 (audit pass, finding S3)
- Fixed: 2026-07-06

## Description

`POST /api/briefings/on-demand` accepted an unbounded `urls` list, extracted sequentially with a
per-URL timeout (30s for the Jina Reader fallback). A large list — accidental or malicious — could
block the request for a long time with no cap and no concurrency limit.

## Fix

Added `_MAX_ON_DEMAND_URLS = 10`; requests exceeding it get a `422` before any extraction work
begins.

## Regression tests

`tests/api/test_briefings.py`: `test_on_demand_rejects_too_many_urls`.
