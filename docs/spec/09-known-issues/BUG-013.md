# Bug: BUG-013 Malformed music_assets.json crashed draft/tts_prep

## Metadata

- Bug ID: `BUG-013`
- Severity: Medium
- Status: fixed
- Found: 2026-07-06 (audit pass, finding R5)
- Fixed: 2026-07-06

## Description

`music.load_music_assets()` handled a *missing* `music_assets.json` gracefully (logs a warning,
returns `[]`), but a *malformed* one (invalid JSON, or unreadable for any OS-level reason) raised
uncaught, crashing the `draft`/`tts_prep` stages entirely — failing the whole run over a
non-essential enhancement (background music).

## Fix

Wrapped the read/parse in a `try/except (json.JSONDecodeError, OSError)`, degrading to the same
"no music will be selected" behavior as the missing-file case, with a `WARNING` log.

## Regression tests

`tests/services/test_music.py`: `test_load_music_assets_returns_empty_on_malformed_json`,
`test_load_music_assets_returns_empty_on_unreadable_file`.
